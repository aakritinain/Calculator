# Arithmetic Expression Calculator

A Java-based arithmetic expression calculator with a graphical user interface (GUI) built using Java Swing.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Modulus
- Power
- Parentheses
- Decimal numbers
- Expression history
- Clear and backspace buttons
- Input validation
- Error handling
- GUI interface

## Technologies Used

- Java
- Java Swing
- Stack
- ArrayList


## How to Run

Compile:

```bash
javac ArithmeticExpressionCalculator.java
